# Разбор обращений

Небольшой скрипт для автоматической классификации обращений студентов и
генерации черновика ответа.

## Что умеет

Скрипт читает обращения из `messages.txt` и для каждого определяет категорию:

- `справка` — информационный вопрос или запрос услуги;
- `жалоба` — сообщение о проблеме;
- `другое` — остальные обращения.

После классификации скрипт выводит черновик ответа на русском языке.

## Запуск

Требуется Python 3.9+.

```bash
python main.py
